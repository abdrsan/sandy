## Исправления, внесённые при проверке

- Отложенное чтение картинки из буфера отменяется после остановки мониторинга
  и не сохраняет изображение, если сохранение уже выключено.
- Вытеснение карточек с полки по лимиту удаляет их из выделения.
- Конвертер принимает узкий неразрывный пробел в числах, например `1 234,56`.
- При смене исходной валюты исчезает прежний результат до получения новых курсов.
  Запоздавший ответ для старой валюты не заменяет текущую таблицу.
- Повреждённые таблицы курсов и некорректные значения не создают вымышленные курсы.
- Нечитаемый файл телесуфлёра сохраняется отдельно до записи нового текста;
  редактирование останавливает прокрутку и возвращает её в начало.

Резервный адрес курсов соответствует [документации поставщика](https://github.com/fawazahmed0/exchange-api#additional-fallback-url-on-cloudflare).
Первый запрос с User-Agent Python получил HTTP 403; запрос с User-Agent приложения
получил HTTP 200. Это проверка доступности из текущей среды, а не гарантия доступности
сервера в дальнейшем.

## Что остаётся проверить руками

Инструмент управления окнами видит процесс и японский системный заголовок,
но снимок прозрачной панели пуст, а нажатие возвращает `AXError.notImplemented`.
Полный проход по кнопкам, наведению, drag and drop и закрытию панели через Esc
не завершён. Поэтому утверждать, что абсолютно все функции проверены в интерфейсе,
нельзя.

Также не включалась настоящая блокировка клавиатуры, не выдавался доступ к
пользовательскому календарю и не устанавливались hooks в настоящую конфигурацию
Claude. Для окончательной проверки используйте [список перед выпуском](release-checklist.md).
