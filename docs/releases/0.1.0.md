# Sandy 0.1.0

Первая версия Sandy с отдельной Git-историей и новым оформлением.

- Имя Sandy в интерфейсе, локализациях, исполняемом файле и установочном образе.
- Собственные идентификатор приложения и каталоги настроек и снимков экрана.
- Новая иконка и обновлённые инструкции по сборке.
- Лицензия и уведомления о стороннем коде включены в приложение.

Локальная сборка подписана ad-hoc. Публичный релиз требует собственной
подписи Developer ID и нотаризации Apple.
