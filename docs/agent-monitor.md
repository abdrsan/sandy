# Мониторинг AI-сессий в Sandy

## Подключение

1. Соберите приложение с интеграционным хелпером `sandy-agent` и откройте
   `build/Sandy.app`.
2. В настройках Sandy найдите «Мониторинг агентов», включите мониторинг и
   нужные источники: Claude Code, Codex или оба.
3. Для Claude Code нажмите «Установить hooks Claude». Эта кнопка запускает
   `install-claude-hooks`; приложение не меняет настройки агента при запуске
   или при переключении вкладки. Кнопка удаления вызывает `uninstall-claude-hooks`.
4. Включите уведомления отдельным переключателем, если они нужны. Только это
   действие может вызвать системный запрос разрешения.

Какие сессии CLI и Desktop доступны, откуда хелпер получает события и как
он устанавливает hooks — описано в `docs/agent-bridge.md`, которое сопровождает
интеграционный хелпер. Интерфейс сам не читает каталоги Claude/Codex, не запускает
задачи агентов и не выполняет запросы к моделям.

Если хелпер ещё не собран, Sandy показывает сообщение об отсутствующем хелпере.
Проверяемый путь — `Sandy.app/Contents/Helpers/sandy-agent`. После его появления
нажмите «Повторить». Демонстрационных сессий в приложении нет.

## Панель и состояния

Вкладка «Агенты» находится в начале правого ряда. Она показывает источник,
проект, состояние, последнюю операцию, наблюдаемое активное время и доступные
счётчики токенов. Кнопка папки раскрывает проект в Finder. Идентичность сессии
состоит из источника и `session_id`: одинаковые ID разных агентов независимы.

| Событие | Состояние |
|---|---|
| `session_started` | Ожидание работы |
| `working` | Работает; увеличивается счётчик операций |
| `waiting` | Нужен ответ пользователя |
| `turn_completed` | Ответ готов; сессия может продолжиться |
| `session_ended` | Сессия закрыта |
| `failed` | Ошибка |
| `usage` | Обновляются накопленные токены, состояние не меняется |
| `disconnected` | Связь потеряна |

Зелёная строка «Ожидание событий агентов» означает, что процесс хелпера запущен.
Это не подтверждение подключения каждого источника. Завершение процесса,
включая выход с кодом 0, считается потерей соединения с долгоживущим монитором,
а не успешным завершением сессий. Автоматического бесконечного перезапуска нет;
для повторного подключения есть кнопка «Повторить».

Отключение мониторинга, всех источников или самой вкладки останавливает хелпер.
Изменение набора источников перезапускает его с соответствующими флагами.
При сне Mac монитор останавливается; после пробуждения запускается снова,
если это разрешено настройками. Пауза и отсутствие связи не превращаются
в состояние «Ответ готов».

## Уведомления

Уведомления отправляются при переходе в «Ответ готов», «Нужен ответ» или
«Ошибка». Одинаковые события и повторяющиеся состояния не создают новые
уведомления. Исторические события до подключения не вызывают уведомлений.
Нажатие открывает вкладку «Агенты», выбирает сохранённую сессию и раскрывает
панель на несколько секунд, чтобы до неё можно было добраться курсором.

В системном уведомлении находятся только тип события и название источника.
Проект, путь и операция туда не попадают. Проекты и операции можно дополнительно
скрыть существующим режимом приватности Sandy для раздела «Агенты».

## Статистика и хранение

Переключатель «Аналитика» группирует сессии по источнику и пути проекта.
Счётчик операций считает принятые события `working`, а не строки изменённого кода.
Токены — накопленные значения сессии: новый снимок заменяет прежний максимум,
а не прибавляется к нему. Если по части сессий нет показателя, итог для этой
группы отображается как «Нет данных». Это не оценка стоимости и не лимит подписки.

Активное время считается только в состоянии `working` после фактического
получения события. Ожидание, сон, выключенный мониторинг и время между запусками
Sandy не учитываются. Поэтому время означает наблюдаемую Sandy работу; оно может
быть меньше полной продолжительности сессии, запущенной до подключения.

История находится в `~/Library/Application Support/Sandy/Agents/history.json`.
Сохраняются только метаданные сессий, счётчики и ограниченный набор ID событий
для удаления повторов. Настройки мониторинга находятся в `config.json`.
Сырые payload, промпты, ответы, stdout/stderr команд и ключи не сохраняются.
Диагностика хелпера не записывается интерфейсом.

История ограничена последними 30 днями и 2000 сессиями. Запись атомарная;
файл получает права `0600`, созданная папка — `0700`. Если файл повреждён или
слишком велик, Sandy сообщает об этом и не перезаписывает его. На панели
появляются кнопки открытия файла и повторной проверки. Если уже поступили новые
сессии, переместите прежний файл в резервную копию и нажмите «Повторить»:
сохранится текущая история из памяти. Пока новые сессии не поступали, можно
исправить прежний файл и перечитать его. Новые события до восстановления записи
доступны только в памяти.

## Контракт и проверки

Приложение запускает хелпер через `Process`, без shell, и читает JSONL из stdout.
Поддерживается `schema_version: 1`, дробные и целые секунды ISO 8601, CRLF,
разделённые чтениями UTF-8 символы и последняя строка без перевода строки.
Неизвестные поля отбрасываются; некорректные и слишком длинные строки
пропускаются без вывода содержимого. Максимум строки — 64 КиБ.

`Tests/SandyTests/Agent*.swift` проверяют протокол, переходы, параллельные
сессии, дедупликацию, накопительный usage, восстановление, паузы, управление
процессом и явный запрос разрешения. Тестовые данные и исполняемые фикстуры
используются только в тестах, в отдельных временных папках.
