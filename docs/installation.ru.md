# Настройка Sandy на Mac

Эта инструкция устанавливает текущую настольную версию из исходников.
Мобильное приложение ещё не реализовано: [план доступа с телефона](mobile-security-review.ru.md).
Обзор возможностей: [README](../README.ru.md).

## Что понадобится

- Mac с macOS 15 или новее. Версию можно посмотреть в меню Apple → «Об этом Mac».
- Интернет для загрузки исходников, инструментов и при необходимости языковых пакетов.
- Swift 6 или новее и Python 3; актуальных Xcode Command Line Tools достаточно.
- Для мониторинга — отдельно установленный локальный Claude Code или Codex.
  Остальные разделы работают без них.

Полный Xcode нужен только если установленный набор Command Line Tools
не содержит совместимого компилятора/SDK. Для сборки настольного Sandy
не требуется платная учётная запись Apple Developer.

## Шаг 1. Установить инструменты

Откройте Программы → Утилиты → Терминал и вставьте команду:

```sh
xcode-select --install
```

Подтвердите установку в окне macOS и дождитесь окончания. Если инструменты
уже установлены, это нормальный результат. Проверьте:

```sh
swift --version
python3 --version
```

Ожидаемый результат — версия Swift 6 или новее и Python 3. Если `swift` отсутствует
или версия старее, обновите инструменты через обновления macOS либо установите
актуальный Xcode. Если `python3` отсутствует, установите Python 3 до сборки.

## Шаг 2. Скачать исходники

На странице репозитория в GitHub нажмите Code → Download ZIP. Распакуйте архив.
Можно хранить проект, например, в папке Documents. Не запускайте сборку из
неразобранного ZIP или из окна предварительного просмотра архива.

Откройте Терминал. Напечатайте `cd ` с пробелом, перетащите распакованную папку
в Терминал и нажмите Return. Так путь с пробелами будет введён корректно.

Проверьте содержимое:

```sh
ls Package.swift Scripts/bundle.sh
```

Оба файла должны существовать. Ошибка «No such file or directory» означает,
что выбрана другая папка; повторите переход через `cd`.

## Шаг 3. Собрать приложение

```sh
./Scripts/bundle.sh
```

Первый запуск компилирует проект; дождитесь строки об успешном завершении.
Скрипт проверяет локализации, собирает приложение и хелперы, создаёт бандл
и проверяет его подпись. Результат — `build/Sandy.app`.

```sh
open build
```

В Finder перетащите Sandy.app в «Программы». Если там уже есть Sandy,
сначала закройте запущенное приложение и только затем заменяйте его.
Откройте Sandy из «Программ».

Для экспериментов можно запустить `open build/Sandy.app`, но прежде чем
включать автозапуск и устанавливать hooks Claude, выберите постоянное место
приложения: путь к хелперу записывается в hooks.

## Шаг 4. Найти панель

Sandy не показывает обычного окна и значка в Dock. Попробуйте любой способ:

1. Наведите курсор на вырез MacBook или середину верхнего края экрана без выреза.
2. Нажмите **Control + Option + Пробел**.
3. Используйте значок Sandy в строке меню.

Нажмите сочетание повторно, чтобы закрыть панель. Esc тоже закрывает её,
если его не обрабатывает активный редактор. Щелчок в другом приложении
завершает работу с панелью с клавиатуры.

Если macOS не разрешает открыть скачанную ненотаризованную копию, действуйте
по [инструкции Apple](https://support.apple.com/en-us/102445): после первой
попытки запуска откройте Системные настройки → Конфиденциальность и безопасность
и, если доверяете происхождению сборки, используйте «Всё равно открыть».
Не отключайте Gatekeeper. Локальная ad-hoc подпись не равна публичной
нотариальной проверке Apple; выпуск описан в [signing.md](signing.md).

## Шаг 5. Настроить язык, клавиши и вкладки

В Sandy откройте вкладку с шестерёнкой:

| Настройка | Результат |
|---|---|
| Общее → Язык | Немедленно меняет язык панели; системные диалоги изменятся после перезапуска. |
| Общее → Сочетание клавиш | Выбирает один из четырёх вариантов или отключает вызов с клавиатуры. |
| Показывать в панели | Убирает ненужные вкладки. |
| Экраны | Управляет несколькими мониторами и полоской на экране без выреза. |
| Запускать при входе | Включает запуск Sandy после входа в macOS. |
| Показывать значок в строке меню | Скрывает или возвращает значок. Повторный запуск из Программ также возвращает его. |

Языки интерфейса: English, Русский, Қазақша, Deutsch, Français, Español,
简体中文 и 日本語. Языковая пара переводчика настраивается отдельно; по умолчанию EN ↔ RU.

## Шаг 6. Выбрать способ сохранения картинок

В «Снимки экрана» проверьте переключатель сохранения из буфера. По умолчанию
он включён и сохраняет любые PNG/TIFF-картинки из буфера, а не только снимки.
Каталог — `~/Pictures/Sandy`. Его можно открыть и очистить из настроек Sandy.
Очистка удаляет сохранённые там картинки; исходные файлы на полке вне этой
папки она не удаляет.

«Наблюдать за папкой снимков» включается отдельно: выберите папку в системном
окне. Разрешение записи экрана для этих функций не требуется.
Текстовая история буфера по умолчанию не сохраняется после выхода. В настройках
«Буфер обмена» можно включить сохранение между запусками и выбрать размер истории.

## Шаг 7. Подключить агентов и уведомления на Mac

1. Убедитесь, что установлен и запускается нужный локальный агент.
2. В настройках Sandy откройте «Мониторинг агентов», включите мониторинг
   и Claude Code/Codex.
3. Для Claude Code нажмите «Установить hooks Claude». Установщик сохраняет
   существующие hooks и резервную копию настроек. Для Codex используются
   поддерживаемые локальные журналы; кнопка установки Claude ему не нужна.
4. Запустите новую задачу или продолжите локальную сессию. Откройте «Агенты».
   Должна появиться реальная сессия. Статус запущенного хелпера сам по себе
   ещё не доказывает получение событий каждого источника.
5. Включите «Уведомления агентов» и разрешите уведомления в окне macOS.
6. При необходимости проверьте Системные настройки → Уведомления → Sandy
   и режим «Фокусирование».

На Mac возможны уведомления о готовом ответе, запросе ввода и ошибке, если
источник передал событие. Codex не записывает все запросы разрешений и ошибки
в доступный журнал; отсутствие уведомления не доказывает отсутствие проблемы.
Облачные задачи не поддерживаются. Sandy не подтверждает команды и не заменяет
терминал агента. Подробно: [agent-bridge.md](agent-bridge.md).

## Шаг 8. Включить только нужные разрешения

| Функция | Действие |
|---|---|
| Календарь | Откройте вкладку, нажмите кнопку доступа, разрешите чтение и выберите календари. |
| Перевод | Выберите исходный и целевой языки в настройках; через «Языки перевода…» скачайте пакеты и нажмите «Повторить». |
| Очистка клавиатуры | Прочитайте инструкцию разблокировки в самой панели и предоставьте Универсальный доступ, если хотите использовать функцию. |
| Управление плеером | При переходе на запасную интеграцию macOS может запросить Автоматизацию/Универсальный доступ. |

Глобальный вызов панели не требует Универсального доступа. При первом запуске
Sandy не запрашивает все разрешения сразу. Файлы заметок, заготовок и сценария
телесуфлёра хранятся локально без отдельного шифрования.

## Обновление, перенос и удаление

**Обновление:** закройте Sandy, получите новые исходники, повторите сборку,
замените приложение в том же месте в Программах и запустите снова.

**Перенос:** перед переносом удалите hooks через прежнюю копию Sandy; после
переноса установите их из новой. Так Claude не будет ссылаться на старый путь.

**Удаление:** удалите hooks, выключите автозапуск, закройте приложение и удалите
Sandy.app. Данные остаются отдельно. Если хотите стереть их, сначала проверьте
содержимое `~/Library/Application Support/Sandy` и `~/Pictures/Sandy`, затем
удалите нужные файлы через Finder. Папки можно открыть через «Переход → Переход
к папке…». Резервные копии конфигурации Claude не удаляйте вслепую.

## Проверка разработчиком

```sh
./Scripts/test.sh
./Scripts/test-helper.sh
```

Вторая команда требует собранного приложения. Полный протокол и границы проверки:
[functional-check.md](functional-check.md). Мобильная доставка не входит в эту
проверку: для неё ещё нужны клиент телефона, канал связи и испытания на устройстве.
