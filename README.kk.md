Телефоннан қол жеткізу әзірге жоспарланған. Sandy MIT лицензиясымен таралған
[Cyclop](https://github.com/akalikbergenov/cyclop) жобасына негізделген.

MacBook экранының ойығын жұмыс панеліне айналдыратын macOS қолданбасы.
Меңзерді ойыққа апарсаңыз, музыка басқаруы, файл сөресі, алмасу буферінің тарихы,
дайын мәтіндер, күнтізбе, аударма, валюта айырбастау, телесуфлер және жазбалар ашылады.

**«Агенттер»** қойындысы жергілікті `sandy-agent` көмекшісі арқылы қолдау
көрсетілетін Claude Code және Codex сессияларын бақылайды. Ол қатар жүретін
сессияларды, ағымдағы әрекеттерді және жобалар бойынша сақталған статистиканы
көрсетеді. Жауаптың дайын болуы, енгізуді күту және қателер туралы хабарландыруларды
қосуға болады. Баптауларда бақылау мен дереккөздерді қосыңыз; Claude хуктары тек
арнайы түймемен орнатылады. Қосу жолы мен шектеулер:
[агенттерді бақылау](docs/agent-monitor.md) (орыс тілінде).

Sandy жобасын Abdirakhym дамытады. Жоба **0.1.0** нұсқасынан бастап жеке Git
тарихымен жүргізіледі. Үшінші тарап коды туралы мәлімет `THIRD_PARTY_NOTICES.md`
файлында беріледі.

## Тілдер

Интерфейс ағылшын, орыс, қазақ, неміс, француз, испан, жеңілдетілген қытай және жапон
тілдерінде қолжетімді. Баптаулар → Жалпы → Тіл бөлімінде тілді таңдаңыз:
панель бірден өзгереді. «Жүйе тілі» macOS тіл баптауларына сәйкес келеді.
Жүйелік рұқсат сұраулары Sandy қайта іске қосылғаннан кейін жаңа тілге ауысады.
Интерфейс тілі «Аудару» қойындысындағы тілдер жұбын өзгертпейді.

## Жылдам пернелер

Меңзер тұрған экранда панельді ашу үшін **Control + Option + Бос орын** пернелерін
басыңыз. Сол тіркесімді қайта басу, Esc немесе басқа қолданбаны шерту панельді
жабады. Пернетақтамен жұмыс істегенде панель ашық қалады. Баптаулар → Жалпы
бөлімінде басқа тіркесімді таңдауға немесе оны өшіруге болады. Бұл функцияға
Әмбебап қолжетімділік рұқсаты қажет емес.

## Жинау және іске қосу

macOS 15 немесе одан кейінгі нұсқасы және Swift 6 қажет. Xcode Command Line Tools
жеткілікті. Жоба қалтасында орындаңыз:

```sh
./Scripts/bundle.sh
open build/Sandy.app
```

Жергілікті жинаққа ad-hoc қолтаңбасы қойылады. Developer ID қолтаңбасы мен Apple
нотариаттық тексеруінен өткен шығарылым үшін өз Apple Developer тіркелгіңіз қажет:
[нұсқаулық](docs/signing.md) (орыс тілінде).

```sh
./Scripts/test.sh        # Тесттер мен аудармаларды тексеру
./Scripts/test-helper.sh # Жинаудан кейін медиакөмекшіні тексеру
./Scripts/dmg.sh         # build/Sandy-0.1.0.dmg бейнесін жасау
```

Нұсқа `Scripts/version` файлында көрсетіледі. `Scripts/release.sh` скриптін
қолданар алдында өз қашықтағы репозиторийіңізді баптаңыз.

## Деректер мен рұқсаттар

- Қолданба идентификаторы: `com.abdirakhym.sandy`.
- Баптаулар, дайын мәтіндер және жазбалар: `~/Library/Application Support/Sandy`.
- Алмасу буферінен алынған экран суреттері: `~/Pictures/Sandy`.
- Күнтізбе мен пернетақтаны бұғаттау тиісті функцияны пайдаланғанда ғана
  Күнтізбеге және Әмбебап қолжетімділікке рұқсат сұрайды.
- Агент хабарландыруларына рұқсат оларды қосқанда ғана сұралады. Тарих
  `~/Library/Application Support/Sandy/Agents/history.json` файлында сақталады;
  бақылау интерфейсі промпттар мен жауаптарды сақтамайды.
- Аударма macOS Translation.framework және жүктелген тіл бумалары арқылы жұмыс істейді.
- Валюта конвертері ашық айырбас бағамдарын жүктейді. Spotify қосалқы механизмі
  мұқабаларды жүктеуі мүмкін. Агенттер статистикасы осы Mac құрылғысында қалады;
  телеметрия және автоматты жаңарту қызметі жоқ.

Sandy өз баптаулары мен деректерін бөлек сақтайды. Басқа қолданбаның деректері
автоматты түрде көшірілмейді. Толығырақ: [SECURITY.md](SECURITY.md) (орыс тілінде).

## Әзірлеу

SwiftUI және AppKit коды — `Sources/Sandy`, медиакөмекші —
`Sources/SandyMediaHelper`, аудармалар мен белгіше — `Resources`, жинау мен
буып-түю скрипттері — `Scripts` қалтасында.

Өзгерістер енгізер алдында [архитектураны](docs/architecture.md) (ағылшын тілінде),
[әзірлеу ережелерін](CONTRIBUTING.md) және [шығарылым алдындағы тексерулерді](docs/release-checklist.md)
(орыс тілінде) оқыңыз. Now Playing жеке macOS фреймворкін және жүйелік Perl
көмекшісін пайдаланады; macOS жаңартулары бейімдеуді қажет етуі мүмкін.
Қолданба App Store арқылы таратуға жарамайды.
